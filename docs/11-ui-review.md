- Chromium系ブラウザーで、CSS表示幅320 / 390 / 768 / 1024 / 1440pxの比較作成・比較結果・ケース明細、計15組を確認。ページ全体の横はみ出しと主要controlの領域外へのはみ出しは0。
- 長い日本語名と連続英字を含むpresetを複数複製して上記の幅を確認。横長の計画表はdialog内のscrollへ限定。
- 1 / 3 / 5回と自由入力7回、セット切替、モデル除外、preset複製、回数の計画反映を確認。0・負数・小数・空欄では確認操作を無効にする。
